# Product

## Name

Project Desk

## Who It Is For

You are building for one person who needs a simple place to track small software projects.

## Problem

Your project notes, status, and next step are spread across chats and documents. You lose time rebuilding context when you come back to the work.

## Promise

You can sign in, create a project, record what it is, and see whether it is still an idea, being built, or launched.

## First Release

A signed-in user can:

- create an account
- sign in and sign out
- reset a forgotten password
- create a project
- view their projects
- edit a project
- delete a project
- update their name and password

Each user can only access their own records.

## Not in the First Release

- teams
- billing
- file uploads
- notifications
- AI features
- public project pages

## Success Check

The first release works when a new user can create an account, create a project, sign out, sign back in, and find the same private project waiting for them.

When you turn this starter into your product, rewrite this file before you ask your agent to build. Keep the first release small enough that you can test it with a real person.
