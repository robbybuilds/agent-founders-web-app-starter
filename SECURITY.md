# Security Reports

Do not include a secret, access token, private customer record, or exploitable production detail in a GitHub issue.

Send a private message to Rob inside Agent Founders Club. Include the affected file or route, the behavior you observed, the smallest safe reproduction, and the impact you believe it has.

If you accidentally commit a secret, revoke it at the provider first. Removing it from the latest commit is not enough because Git history can retain it.
