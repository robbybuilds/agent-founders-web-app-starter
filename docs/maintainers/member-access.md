# Member Access

## Current v1 Location

The private repository lives under `robbybuilds` during development. Transfer it to the Agent Founders Club organization before member distribution.

## Give a Member Access

1. Collect the member's exact GitHub username.
2. Open the repository on GitHub.
3. Open **Settings**, then **Collaborators and teams**.
4. Click **Add people**.
5. Choose the member and give them **Read** access.
6. Send the member the private repository link after they accept the invitation.
7. Tell them to click **Use this template** and create a **Private** repository under their own account.

Do not add members as repository writers. They need to read and use the template, not change the canonical starter.

When membership ends, remove access to the canonical repository. Their own repository and any local copy remain theirs.

## Scale Later

Manual invitations are the right v1 process because you can see where members get stuck. Automate invitations only after the username collection and removal rules are stable.
